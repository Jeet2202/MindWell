# MindWell - Mental Health Support Platform

MindWell is a modern, responsive web application designed to support mental wellness for students and connect them with improved counseling services.

## 🚀 Features

### **1. Landing Page**
- **Modern UI/UX:** Glassmorphism design, smooth scrolling, and animated elements.
- **Responsive Layout:** Fully optimized for mobile, tablet, and desktop.
- **Service Showcase:** Highlights key offerings like 1-on-1 counseling, group support, and resources.

### **2. Student Dashboard**
- **Mood Tracker:** Interactive emoji-based mood logging with real-time chart updates.
- **Appointment Booking:** 
  - Calendar-style booking interface.
  - Counselor selection with profiles.
  - Session type selection (Individual/Group).
- **Appointment Management:** Tabs for Booking, Upcoming, and History.
- **Progress Visualization:** Visual charts tracking mental wellness trends.

### **3. Learn Page (Mental Health Resources)**
- **Learning Modules:** Interactive courses on anxiety, stress, and sleep.
- **Assessments:** Standardized tests (GAD-7, PHQ-9) with immediate feedback.
- **Peer Support Chat:** Simulated chat rooms for community support.

### **4. Doctor Dashboard**
- **Overview Stats:** Key metrics at a glance (appointments, alerts, active students).
- **Patient Management:** List view with risk stratification and status tracking.
- **Schedule Management:** Daily agenda view.
- **Critical Alerts:** Widget for high-priority patient notifications.

## 🛠️ Technology Stack
- **Frontend Framework:** React (Vite)
- **Styling:** Tailwind CSS + Custom CSS (Glassmorphism, Animations)
- **Icons:** FontAwesome
- **Charts:** Chart.js & React-Chartjs-2
- **Routing:** React Router DOM

## 📦 Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    cd MindWell/frontend
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

4.  **Build for production:**
    ```bash
    npm run build
    ```

## 🎨 Design System
The project uses a custom design system built on top of Tailwind CSS, featuring:
- **Primary Gradient:** Purple to Indigo
- **Secondary Gradient:** Pink to Orange
- **Glassmorphism:** Translucent UI elements with backdrop blur
- **Animations:** Floating shapes, fade-ins, and smooth transitions
